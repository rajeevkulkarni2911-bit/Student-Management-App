# Student Management & CGPA Dashboard
A pyhton-based student management system built using streamlit and SQlite.

## Features
- Add Students
- View Students
- Delete Students
- Add Subjects Marks
- Calculate Grades
- Calculate SGPA
- Student performance dashboard
- SGPA visualization
- SQLite database

## Technologies Used
- Python
- Streamlit
- SQLite
- pandas
- Git 
- GitHub
